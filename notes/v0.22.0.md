Settings, on `lode ,`.

Nine panes carrying every option the config file holds, and nothing
else — the window and the file cannot drift in either direction, and a
test enforces it. The grammar is the house's, recombined: digits
address panes the way `lode 1…9` addresses windows, letters address
rows the way hints label a window, `/` searches across every pane, and
escape pops one layer at a time. Tab walks every control; return is
the only commit, and a field left any other way snaps back to what
the file says. Every row wears the config path it writes, so the
window teaches the file as you use it, and the doctor's findings
render beside the rows that fix them. The graph stays where
addressing happens — ⌘K and the file — never in a pane.

The profile registry is gone. A browser profile is referenced by
naming it — `brave:Work`, `chrome:Personal` — the same form in routes,
links, the fallback, meeting calendars, and the graph. There is
nothing to declare and nothing to keep in sync: the browser's own
profile list is the authority, and every reference is checked against
it, so a renamed profile surfaces as one flagged line naming the
exact config path. On first launch this release rewrites your config
once — references written through the old registry are translated
(`"x.com": "work"` becomes `"x.com": "brave:Work"`) and the profiles
section is dropped. Nothing else in the file changes.

The lode key can now be the left ⌘ instead of the right, chosen in
General. Hint letters follow your keyboard layout automatically, so a
Dvorak or AZERTY home row labels windows with its own keys. The
sticky-hint relabel delay stopped being a setting and got better
instead: a knob someone reaches for means the default is wrong, and a
wrong default is ours to tune once, for everyone. Help survives every
toggle — the cheat sheet is no longer a feature you can turn off; the
select gesture took its switch.

The menu bar slimmed to verbs. Preferences live in Settings, and the
config file has always reloaded itself on save, so Reload Config,
Reveal Config in Finder, and the meetings item stepped down. What
remains does things: the walk, updates, the browser role, the coach's
inbox, the window, the file, the log. And the clicked-links switch in
Settings now takes and returns the browser role for real — the same
doors the menu item opens — instead of writing a wish into the config.

Retired quietly, with migrations: the name nothing read, the
double-tap grammar, hand-set hint letters, and the auto-reload toggle,
because watching the file is simply how the config works.
