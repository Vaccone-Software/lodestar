A release that pastes a picture copied from a browser as the picture, starts an update's new build once instead of twice, and has Lodestar say what held it when it is slow to answer.

A picture copied in a browser and pasted from Keep with a plain letter or ⌥ now pastes the picture. A browser puts the picture's web address on the clipboard ahead of the picture itself, and Keep used to paste only that address, so an app that takes pictures but not addresses pasted nothing, or a link. ⇧ still pastes everything that was copied, the address and the picture both.

An update now starts its new build once. It used to start twice in about two seconds, once on its own and again when macOS took over running it, handing your keys from one to the other each time. When macOS is already the one running Lodestar, it now restarts it in place with the new build. In every other case the update starts as it did before.

When Lodestar's main thread is a second late to answer, Lodestar now notes in its log what that thread was doing, up to four times while it stays late. It already noted that the thread was late but never why, so a stall can now be traced to its cause. Nothing is noted when the thread answers on time.
