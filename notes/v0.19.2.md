Going somewhere asks the machine once instead of four times.

Every summon — the letter chains, the launcher, anything that puts you in
front of a window — begins by working out which of an app's windows are
still alive. That question is not cheap: it lists every window on the
machine and then asks each candidate's application, one at a time, whether
it is still there. On a working desktop with 275 windows open, listing them
takes about eight milliseconds, and each application asked takes its own.

Lodestar was asking four times for every summon. Twice because the code
checked whether the answer was empty and then went and got the answer again,
and twice more because the line written to the log and the decision about
where to send you each fetched their own copy. Roughly thirty milliseconds
per summon, three quarters of it spent finding out the same thing over
again, and for an app with eight windows open it meant thirty-two
conversations with that app where eight would do.

It asks once now. The saving is largest exactly where it was most annoying —
a browser with many windows, an app that is slow to answer — and it is the
most frequent thing Lodestar does.

There is a second, smaller version of the same mistake, in a worse place.
The chain guide — the panel that appears under your fingers as you type a
chain and shows what each letter would do — draws an icon beside every row,
and it was fetching those icons from the system every single time it drew,
inside the code that handles the keystroke. That code runs before the key is
allowed to continue to whatever you are typing in, so it is the one place
where slowness is not Lodestar's alone. A twelve-row guide cost about forty
milliseconds the first time and three every time after. Icons are now
resolved once and remembered until the list of installed applications
changes.

Nothing about how anything works has changed; this release is the same
Lodestar answering faster. The one visible difference is in the log, where
the summon line now records how long the lookup took — and, more usefully,
now lists the windows the decision was actually made from. The two lookups
could see different worlds, so what the log said and what Lodestar did were
not always the same thing.
