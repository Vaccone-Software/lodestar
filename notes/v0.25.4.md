Shift means more.

Scroll mode had one speed. `scroll.speed` set it, and the hand either
lived with it across a long page or reached for `d` and counted. That is
a decision at the moment of use, which is the thing this project exists
to remove, so the answer is not a second speed to tune but a modifier the
hand already owns: hold shift.

`⇧J` `⇧K` `⇧H` `⇧L` move three times as fast, and the modifier is live.
Press shift in the middle of a glide and it sprints; let it go and it
settles, without lifting the key. Smooth off, the same shift triples the
step. `⇧D` and `⇧U` move a whole page instead of half. `⇧G` already meant
the end of the document, so the mode now reads one way throughout: the
key names the direction, shift names how much, and there is nothing new
to configure because three is not a preference.

The scroll guide says so on each row, and the guide's one-line summary
of the mode ends with "⇧ for more."
