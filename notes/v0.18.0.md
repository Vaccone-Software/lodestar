Nothing Lodestar writes can cost you your config any more.

Two of the four places that edited the config file read it with a fallback
that treated "this file did not parse" as "there is no file" — and then
wrote. The result was quiet and total: a `//` comment left in
`lodestar.json` while you were reading the schema, then one toggle of the
default browser or one "never save from this app", and the file came back
holding the single key that had just been set. Graph, browser profiles,
links, routes, key overrides, gesture switches: gone, atomically, with
nothing said and no backup. `lodestar check` and `lodestar diagnose` reached
the same path from the other side, so the command you would run to find out
what happened was the command that finished the job.

There is one read-modify-write now, and one rule inside it: a file that
exists and does not parse is never written over. A file that does not exist
is a first write, which is the only case that was ever supposed to reach
defaults. What you get instead of a silent replacement is a problem you can
see, with your file exactly as you left it.

Gestures no longer wait on a hung app. Moving windows means talking to them
through accessibility, one call at a time, and an app that has stopped
answering takes a second to say so. All of that was running inside the event
tap — which is to say inside the keyboard. One beachballing member of a
layout could stall key delivery for every app on the machine, and when
macOS eventually gave up on us, the rest of your chain arrived as letters in
whatever was in front. The decision to swallow a key or pass it on is
knowable without doing any of that work, so that is all that happens in the
tap now; the window moving follows a beat later. A tap that dies without
saying so — which is what revoking accessibility does — is noticed within
five seconds and rebuilt, and a chain left half-typed by the outage is
cleared instead of silently eating everything you type next.

Double-tap works. It has had a schema, a default, a line in the guide, a
consumer and a fully tested detector since it shipped, and no parser, so
`double-tap.cmd` validated, wrote, printed back through `lodestar config`,
and did nothing at all, forever, with no way to tell. Tapping a modifier
twice fires its verb now. The reason it went unnoticed for so long is that
nothing connected the schema to the config the app actually runs on, so
there is a test that walks every option in the schema and fails if any of
them cannot be shown to arrive.

`lodestar config set` can write the keys it always claimed to. Anything
whose keys are yours — hosts under `web.routes`, bundle ids under
`clipboard.exclude-apps` — has dots in the middle of the key, and the
dotted path was split on every one of them, so those settings simply could
not be written from the command line. `unset` was worse: it printed a check
mark and exited successfully while leaving the key in the file. The schema
knows where a name of yours begins, so it decides the split now.

The YAML config is retired. The automatic conversion ran from 0.9.10 and has
done its work; if a `lodestar.yaml` is still sitting in `~/.config/lodestar`
nothing reads it, and it is safe to delete. Upgrading from 0.9.9 or earlier
now starts from defaults.

The rest is a list of things that were each one bad day for somebody. A
release that failed its handover wrote a tombstone so it would not be
installed again, and the tombstone was compared against a string it could
never equal, so a broken build re-downloaded, re-applied and rolled itself
back once a day, every day. A number too large to hold survived into the
config as infinity and made the next write emit something that is not JSON,
after which the file could not be read at all. Parking could be asked to
hide a window at an infinite coordinate when no display was attached, and
could restore one onto a monitor that had since been unplugged; parked
windows are also fenced to the boot that parked them now, because a window
id means nothing after a restart. Undoing a layout on a monitor you had just
unplugged left its windows in the parking sliver with nothing left that knew
where they came from. A display that changed shape — a resolution switch, an
arrangement drag, the Dock appearing — kept a tiling cut for the rectangle
it used to be. A chain written as `"eo": "Outlook"` could not be removed by
the card offering to remove it. The log could tear itself in half when the
updater wrote to it from its own thread. A failed write to the event ring
could replace ninety days of it with the last few seconds. A clipboard index
that would not decode was replaced rather than kept. And an install path
containing an ampersand produced a login item macOS refused, while the log
said it had been installed.
