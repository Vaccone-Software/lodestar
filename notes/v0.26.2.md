The gate opens.

0.26.1 promised that music steps aside while the draft listens, and on
the machine it was built for it never did. The session names the device
it reads, and an engine following the system default reads through a
private wrapper CoreAudio makes for the process — a name that resolves
on the process's own device list to something whose transport says
aggregate, not Bluetooth. The gate asked the wrapper and the wrapper is
not a radio, so it stayed shut, silently.

Now the wrapper is seen for what it is and the gate asks about the
device it wraps, the system default. And the gate speaks when it
declines — no shared radio, nothing playing — so the log can answer
the next question like this in one read.
