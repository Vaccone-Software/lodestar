A reset you can trust.

`lodestar reset-config` now backs up the current file before writing fresh
defaults. A timestamped copy lands beside it, so a reset never costs you a
graph, a registry, or a link. Earlier releases skipped the backup. One lost
config later, this one does not.

The default graph also learned humility. It used to assume Slack, Terminal,
and Outlook were installed. Now it ships two starters that both open
Lodestar itself, the one app every machine has: a leaf (`hyper L`) and a
branch (`hyper E L`), one of each shape the graph knows. Replace them with
the places you actually go.

Also in this release: walking a graph chain to Lodestar reveals the menu
bar, the same as picking it in the searcher, instead of launching nothing
and waiting.
