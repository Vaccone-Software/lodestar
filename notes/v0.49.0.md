Lodestar now needs macOS 27, and in return it is harder to break: what it writes survives a crash, and what it waits for has an end.

Lodestar is now built on Stoic, our open-source library for the parts of
an app that fail rarely and badly. Settings, history, the dictation
journal and saved state are written so that a crash or a full disk
leaves the old file or the new one, never half of each, and a write that
fails is logged instead of lost. A `lodestar config set` from the
terminal and a change in Settings can no longer undo each other. A
second copy of Lodestar no longer takes the first one's control socket.

The editor's model download retries with a growing, slightly random wait
and gives up on an address that does not exist instead of asking for it
forever, and the finished model is swapped into place in one step. The
updater no longer waits forever on a stuck signature check. The watchdog
that restarts a frozen Lodestar no longer mistakes the Mac's own sleep
for a freeze, and if Lodestar keeps failing to start, the watchdog stops
restarting it and says so in the log.

Macs on macOS 26 or earlier stay on 0.48.1: the updater sees that this
build needs macOS 27, says so once, and does not ask again.
