The config learns to say only what you mean.

lodestar.yaml becomes lodestar.json, and the file becomes sparse: it
holds only what differs from the defaults, so a config reads as pure
intent — most are a dozen lines of graph and profiles. The first boot
converts the old file automatically, keeps every setting, and leaves
the yaml in place, inert, until a later release retires it. A yaml
that fails to parse is never converted.

Documentation moves out of the file and lives only in the schema,
where it cannot drift: the $schema key gives any LSP aware editor
completion and hover docs, lodestar schema prints the whole table,
and deleting a key restores its default. Every writer — a hand edit,
⌘K in the searcher, the new command line — converges on the same
canonical bytes.

The command line grows the blessed write path: lodestar config prints
the effective picture, config get reads one value, config set writes
one — validated before a byte moves, refused with the problem named
if it would break anything, applied to the running instance on
success — and config unset is the way back. Agents get the same
contract in AGENTS.md.
