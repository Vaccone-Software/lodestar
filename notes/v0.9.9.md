Updates arrive quietly.

The installed app now keeps itself current. Once a day it reads the
releases feed; when a newer build exists it downloads in the
background, unpacks, and faces a strict gate: signature integrity,
this team's Developer ID, this bundle id, and a version that matches
the release tag. A self-downloaded zip never meets Gatekeeper, so
Lodestar is its own gate — nothing moves until every lock turns.

The swap waits for a quiet moment: no chain pending, no panel open,
ten minutes since the last gesture. Then the new build takes the
session over exactly the way a manual reinstall always has, and a
detached watchdog holds the previous version until the successor
proves it boots — if it never takes the pid file, the old build is
restored and says so. Successful navigation is silent; the one flash
afterward keeps the change honest.

app.auto-update turns it off. The menu bar gains Check for Updates…,
which checks and applies on the spot. Dev builds and translocated
copies never self-update. Homebrew installs update themselves the
same way; the cask now declares it.
