The number row finishes its sentence.

lode 0 now fills the display with the focused window, and lode ⇧0 puts
it beside instead. The whole row reads as one idea: zero collapses to
one window, one through nine pick among many. Anything you maximize
this way also joins the layout, so from that moment it answers to the
digits, to breaths, to orientation, and to undo exactly like something
Lodestar summoned. That is the only way an unmanaged window becomes
managed, and it is deliberate every time.

Two things leave to make room for it.

Sweeping is gone. It parked windows that were already out of sight: a
Lodestar layout always fills its display, so anything not in the
layout was behind something. It could not be undone, and nothing could
bring the parked windows back in one gesture. What it collapsed to was
a tidier list in Mission Control, which is not worth a key.

Adoption is gone with it, and with it the app.adopt-new-windows
setting. A window Lodestar did not summon is now always left exactly
where its app put it: a launcher, a file reveal, a certificate prompt,
a new document. Nothing is rearranged behind you, and lode 0 is how
you say otherwise. Configs that still name the old setting, or the old
gestures.claim switch, will say so on reload rather than pretending.

lode = is retired. It is unbound now, along with the minus key.

Underneath, updates got considerably harder to break. A release that
fails to start is remembered and refused instead of being applied
again on the next check, a stalled download can no longer wedge the
updater, an interrupted handover can no longer leave a stale marker
that reports a success that never happened, and the whole run is now
one piece of state rather than three kept in step by hand.

lodestar schema prints a JSON Schema again, which is what it always
claimed to print. The disk image you install from was redrawn as a
plotting sheet: a measured course between the app and your
Applications folder, with the lodestar itself standing where the
arrow used to be.
