The microphone outwaits the radio.

A Bluetooth headset resting on its music profile must flip to the
hands-free profile the moment the microphone opens, and a start caught
inside the flip fails. The engine rebuilt itself and tried again at
once, still inside the flip, and gave up — so with music playing, the
very state the last release exists for, dictation could fail to start
at all. Measured on the machine this was built against: the first
start from the music profile always fails, and one three quarters of a
second later succeeds.

Now the start waits the flip out, off the main thread, across a few
attempts. A draft closed mid-wait never opens the mic. Nothing else
moved.
