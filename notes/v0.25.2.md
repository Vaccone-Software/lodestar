A span now knows which column it runs down.

Select a few lines inside a card, a message, or the main column of a
page, and the copy comes back with exactly those lines — not the
sidebar's next three items, not the neighboring card's first line, which
is what it used to bring along on any screen wider than one column. The
cause was a small blindness in how the screen is read. Reading order goes
top to bottom, so on a page with a sidebar the lines of the two columns
arrive alternately, and the stitching that turns lines back into
paragraphs only ever asked whether a line continued the one just before
it. The one before was almost always the other column's. So every line
failed the test, both columns fell apart into single lines, and a span
"down the page" walked through all of them.

Now every paragraph stays open while the screen is read, and each line
joins the nearest one it continues, in its own column and its own
window. A card is one paragraph again; so is a column; so is a chat
thread. On the busiest page measured, a feed beside a sidebar, 122
recognized lines used to become 92 pieces and now become 43. The rules
for what belongs together did not loosen at all. They are simply asked of
every paragraph that could answer, instead of only the last one.

The span learned the same lesson. Between means between on the page, not
merely between in the list: the two ends you pick define the column the
selection runs down, and text beside that column is not taken, however
it sorts. Anchor in the sidebar and end in the page and you get both —
crossing columns is still allowed, it just has to be asked for at both
ends.

Two smaller things came out of the same afternoon. Text in one window is
never stitched to text in another, so a reference window beside the one
you are reading stays its own thing — and the invisible overlays some
utilities keep at the top of the screen own nothing, having been caught
claiming a page's first fourteen lines. And a heading tall enough to sort
ahead of a short line beside it can no longer swallow that line into
itself, which it did, silently, in the copy.
