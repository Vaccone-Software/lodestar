Lodestar checks for updates more patiently, keeps its clipboard index private to you, and writes down what its foundations notice.

Lodestar now runs on Stoic 0.3. The update check is a declared
operation: on its own schedule it waits out a busy or briefly
unreachable server instead of failing on the first try, and when you
choose Check for Updates it answers within half a minute. A refused
certificate or a malformed address is no longer asked for again as if
the network had merely dropped.

The clipboard index, and a config file Lodestar creates, are readable
only by you. A file that was written but whose final disk sync failed is
treated as written, with a warning, so a downloaded editor model that is
already in place is never reported as failed and fetched again.

Warnings from Stoic itself (a retry given up on, a write that could not
be confirmed, a launch that could not be recorded) now appear in
Lodestar's log, with private details redacted, so `lodestar diagnose`
shows them.

On a clipboard card too narrow for every clock, UTC now gives way before
a time zone you kept, instead of pushing it off the card in the hours
when UTC is already on the next day.
