A new command, `lodestar transcribe <file>`, hears an audio file with the same ear dictation uses and prints the words. Nothing opens and nothing is typed. Each `--name` is a word to lean toward, and dictation's own list of names is heard too. Add `--json` for the ear that heard it, each word's time and how long it took. It is there for other programs on this Mac that need a phrase written out.

In the commands bar, each row's shortcut and ⏎ now sit on the row's centre, so the column of keys stays straight whether or not a row has a line beneath its title.
