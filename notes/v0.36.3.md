An update that checks the Mac it is going to before it goes.

The next version of Lodestar will ask more of the Mac it runs on: Apple
silicon, and macOS 14 or later. That is what the editor it brings needs,
a language model reading your sentences on the Mac's own graphics chip.
Until now the updater checked that a new version was signed by us and
was the version it claimed to be, and never whether this Mac could open
it. An Intel Mac, or one still on macOS 13, would have installed it,
failed to start it, rolled it back a minute later, and done the same
with every release after.

This version reads what a new build asks for before it installs it. If
this Mac can run it, nothing changes. If it cannot, the update is set
aside, Lodestar says once which Mac or which macOS it needs, and this
Mac stays on the version that works for it.
