Lodestar watches how you reach things, so that one day it can coach.

The observation layer is rebuilt around an event log. What used to be a
handful of running counts is now `events.jsonl`, ninety rolling days of raw
material, with `observations.json` as the running summary that outlives it.
The lesson that forced the change: the old layer averaged at write time, and
when an average turned out to measure the wrong thing, the raw signal was
already gone. Now aggregation happens at read time. When the analysis
improves, it replays history instead of starting blind.

What is recorded, all of it local: the pauses inside an address and whether
the guide was up when a letter landed, chains abandoned and how long the hand
hovered first, the key pressed where the graph expected another, what a
launcher search actually cost in seconds, which application tends to follow
which, and the host a destination opened at. What is never recorded: window
titles, a URL beyond its host, the clipboard, or a launcher query beyond its
first two characters. Nothing leaves the machine. `observations.enabled` set
to false turns all of it off, and off means nothing is recorded and no file
is written. `lodestar observations clear` deletes everything noticed so far.

Behind the data sits an analysis engine. Pauses are judged against what each
chain asks of the hand, not against a constant, so a longer address is never
mistaken for a slower one. Learning curves are fitted per address, which
prices what a new binding costs before it pays. A finding must clear two
gates before the report will say it: it must probably be worth more time than
it costs, relearning included, and it must survive false discovery control
across everything tested at once. Thin data stays silent on its own.

`lodestar observations` prints the report, now with more to say: how often an
address fires blind, where searches keep going, which applications travel
together. `lodestar observations engine` shows the fitted models behind the
verdicts, for eyes that want the working shown.

This release collects and reasons. The coach that acts on it comes next:
recommendations that surface one at a time, in quiet moments, each priced in
the seconds it saves.
