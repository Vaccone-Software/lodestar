The updater takes one flight at a time.

An update run is now a single pipeline from check to swap, and a
second request joins it instead of starting another. Press Check for
Updates twice and the second press tells you what the first is
already doing — checking, downloading, or handing over to the new
build — rather than racing it for the same bundle on disk.

The manual check also narrates: found, downloading, updating, each
step flashed as it happens, so a quiet moment is never mistaken for
a stalled one.

The swap itself grew careful. It refuses to run unless the world is
exactly as expected — the install present, no half-finished swap
lingering beside it — and the watchdog that guards every handover
will only roll back while the previous build is still there to
restore. Nothing is ever deleted unless its replacement is proven
in place.
