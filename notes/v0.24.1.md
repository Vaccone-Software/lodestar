Three ways the aim gets truer.

The matcher now forgives the recognizer's handwriting. Clean-screen
recognition fails almost only by single-glyph twins — a 1 for an l, a
0 for an O, a 5 for an S — and the search was glyph-exact, so typing
the truth sailed past the misread: a quarter of genuine aims this
month ended with visible text unfound. Both sides of the search now
fold through those confusion classes, so what you type — the truth —
finds what the recognizer stored. Every fold maps one character unit
to one, which keeps every match range honest against the original
text: the highlight still promises the screen's own glyphs, misreads
included, and the grounding layer still repairs the copy. The one
real confusion that changes length, rn against m, stays out for
exactly that reason.

A fire that lands in a text input now ends the mode, sticky
included. Focusing a field means the next keystrokes belong in it,
and a sticky mode that stayed up ate them as aiming — the one
contradiction in the chain-click promise, inherited faithfully from
the old hints and now retired.

And the first keystrokes stop racing the sensor. Letters typed in
the beat before the first read of the screen lands were silently
dropped; they are now held and replayed into the first world, so the
hands may start aiming the instant the mode key does. Backspace
walks the held letters back like any others.

Three new tests pin the fold's finds, its honest ranges, and the
sticky exit — six hundred ninety-three in all.
