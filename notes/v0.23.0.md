The graph card speaks profile. ⌘K on a browser row now carries a
Profile row — Tab opens the list, a digit picks, and zero is Inherit,
the bare app that opens whatever the browser opened last — so three
chains can mean Brave as long as each opens a different profile.
Bindings conflict on target, never on app: the card shows every
binding a browser owns wearing the profile it opens, keeps offering
an add while unbound targets remain, and refuses a duplicate by
naming the address that already means it.

The key table speaks your keyboard. Key names, hint labels, and
synthesized keys all read from one table now: ANSI at the floor, the
active layout's own characters adopted wholesale when they cohere
(Dvorak, Colemak), letters and digits alone when umlauts stand in the
way, nothing at all when a layout cannot keep every name alive on
exactly one key — and the config's keys table stays the user's last
word over either. A chip and the key that fires it are the same
character on every layout, the table follows an input-source switch
the moment it happens, and the clipboard's paste lands on the key
that actually types v — which, on Dvorak, it never had.

The months are written down. The event ring holds ninety rolling
days; the coming retrospective speaks from quarters. Every completed
month now archives into rollups.json — counts, sums, and log-moments,
never fitted models, because the archive is the one place there is no
replaying — including every offer the coach made and every answer it
got. The archive is add-only forever: a stored month is never
recomputed, a file written by a newer schema is left untouched,
`lodestar observations` shows what stands, and `observations clear`
takes the archive with it.

And a long review, kept. The coach can no longer swap its standing
offer while the chip is on the glass, so the two gestures always
answer the suggestion that was read. Undoing a cross-display move
returns the window home instead of parking it in the sliver — one
gesture, one undo step, both displays — and a breath restores as one
step too. A launch whose app fronts a login dialog or a splash no
longer full-screens the event and parks the world around it: the
place-vs-event test, retired with adoption, is reborn at the intent
queue. A routed link can no longer vanish behind a browser that
moved to the Trash, profile lists refresh on config reload instead of
serving the boot snapshot, and the searcher's ⌘K finally toggles
closed instead of resetting a typed chain.

The chain clock starts only when lode actually goes down, dies at a
mode's door, and ignores autorepeat — three ways the observation log
was quietly lied to. Select's grounding tries every occurrence of its
anchor and declines when two repairs disagree, never substitutes
collapsed text under a multi-line highlight, and lets Page Down
dissolve a held ghost like any other key. The clipboard leaves the
boot pasteboard off the record — an exclusion that cannot be checked
is not honored by guessing — no longer crashes on a hand-edited pin
index, and never writes undecodable bytes wearing a .png. Settings
edit one table entry at its own path, so a row the loader rejected
survives its neighbor's edit for the doctor to keep pointing at.

The statistics got stricter about themselves. The false-discovery
gate now counts every hypothesis tested — a candidate that failed its
own decision gates stays in the family, because control over the
survivors alone is post-selection and controls nothing — and a
retirement, which rejects no null, stands outside the family instead
of distorting it with a stand-in constant. The learning-curve grid
pays the same bill for every rate it compares: an address whose
regressor collapses gets the honest flat fit instead of silently
buying the wrong pooled rate with its absence. And scrolling left is
left again: the horizontal axis answers a wheel event backwards from
the vertical one, measured now and written down.

Twenty-three new tests pin all of it, six hundred eighty-nine in all.
