The pointer is walked, not warped.

The verified copy asks the app to select a held span by a synthetic
drag, a press inside the first glyph and a release inside the last.
Ghostty takes a press without a position: the position is whatever
the last move or drag left it. So the press started the selection
wherever the pointer had last moved inside the window, the app's copy
came back the wrong length and was overruled, and after Lodestar
warped the pointer home, which tells the app nothing, Ghostty's
remembered position stayed at the end of the previous span. The next
select of the same span selected nothing, no app copy arrived, and
the hand learned to select twice, the first time to put the pointer
in place. The pointer now walks to the first glyph before it presses
and walks home afterward, so the app hears where it is both times.
Apps that read the position off the press itself see one extra move
and nothing else.
