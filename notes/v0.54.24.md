A release that moves Lodestar to Stoic 0.8 and holds all of its code to Stoic's own rules, so failures that used to pass in silence now leave a trace, and timings no longer move when the Mac's clock is set.

Every time Lodestar measures how long something took, it now uses a clock nobody can set. It used to read the time of day, so a clock corrected by the network in the middle of a measurement could make a wait look seconds long or end it early. The times it writes down, in your records and its log, still come from the time of day as before.

About a hundred places where Lodestar carried on after something failed now say so in its log, with what it was doing. A file that could not be written or removed, a folder that could not be made, a journal that would not close: each one used to vanish without a word.

Start at login is steadier. When macOS cannot be asked whether Lodestar's login item is loaded, Lodestar now changes nothing, where it used to load it again on top of one that may have been running. A login item that could not be saved is no longer reloaded from the old one. The `lodestar` command in your terminal is only ever replaced when it points at a Lodestar app, so another tool's command of the same name is left alone, and uninstalling no longer removes it either. The command is replaced in one step, so there is never a moment without it.

A config that cannot be saved now says so in Lodestar's words, and the details go to the log.

Timers that were cancelled at the last moment no longer go off. A card that should have closed when an app's window arrived could stay on screen. The check that restarts a microphone that has gone deaf now counts only time the Mac was awake, so opening the lid mid-draft no longer sets it off before the microphone has had a chance to speak.

Opening the clipboard history no longer reads two of its counters while they are being written. Dictation now keeps a bounded amount of audio for a recognizer that falls far behind, and says so in the log when it lets some go.

Underneath, every format Lodestar keeps on disk that an earlier version may have to read, after an update is rolled back, is now tested against samples of what each release wrote: the queued feedback notes, the config file and Lodestar's state. A change that would leave an older Lodestar unable to read your queued notes now fails before it ships.
