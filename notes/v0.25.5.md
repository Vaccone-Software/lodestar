Three small things, all about the record.

The behavioral record lives in `~/.local/share/lodestar`, and until now
that directory and the files in it were readable by every account on the
machine. The code had asked for owner-only when it created the directory,
but a directory that already existed kept the mode it was born with, and
every atomic save gave its file the process default. The clipboard store
and the control socket were always locked down; the events, the
observations, the log, and the state were not, and those are the
browser-history-grade half. Now the directory is set owner-only on every
launch, every file in it is swept to the same, and every writer of the
record restores the mode after it writes, so a rewrite cannot loosen it
again.

The pulse counted clicks but could not say where they went, by design:
the hands' pulse is app-blind. That left the mouse as the one pool the
coach could see the size of and never name. A click pulse now rides
beside it, one event per quarter hour per app: how many clicks, how many
were hand trips (the previous input was a keystroke, so the hand left
the keys for it), and a histogram of what was clicked by accessibility
role class: button, link, text field, cell. The line is stated where the
code can read it and enforced by the accumulator's own API, which takes
an app name and a role string and nothing else: never a label, a title, a
coordinate, or a URL. The lookup runs off the tap thread with its own
short timeout, so a wedged app can delay the accounting and never the
click. `lodestar observations` shows the pool on a line of its own,
described and not judged, and the monthly rollup archives it by app;
archives that predate the column still read.

Select mode now stamps the moment it first had anything to offer:
`select-capture`, entry to the first adopted sense, pixels or tree,
whichever landed first, and `select-ocr` for the accurate pass. The
audit's median of 0.89 seconds to the first key was mostly this wait,
and the instrument had no line for it.

And the harness has its first scroll scenarios. The wheel is caught
before the window server sees it, a held j glides on its real timer, and
the tests hold yesterday's promise: shift pressed mid-glide triples the
tick, released it settles, and the key never had to lift.
