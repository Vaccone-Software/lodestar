Liveness is asked, not awaited.

Chromium never announces a window's death. Close a Brave window and the
notification that should report it simply never arrives, so Lodestar's
model kept believing in windows that no longer existed. A profile summon
could pick one of these ghosts: everything else parked, Brave came
forward, and nothing arrived. The longer a session ran, the more ghosts
accumulated, and the more often a summon went blank.

Now every death signal funnels into one path, fed by two probes. A single
window server query buries every record the server no longer lists. And
before any window is placed, raised, or saved into a breath, Lodestar asks
its element directly: a dead element answers with a distinct error, and
only that error kills. A frozen app reads as alive, never as dead, so a
beachball can never take its windows with it.

Summon ties are no longer luck. When two windows match the same
destination, the most recently focused one wins, then the newest.
