Naming a destination no longer means editing a file.

⌘K in the web bar acts on the row in front of you, and the row decides
what is on offer. A bare domain can become a named link, so youtube.com
answers to yt from then on, or a route, so anything matching a pattern
opens in one profile from now on. A link can be routed or removed. A
search can be routed too, because a pattern is matched against whatever
you typed and not only against hosts. Every one of those writes into the
config file in the shape a hand edit would have taken, so the file and
the cards stay one source of truth.

The profile is optional, and left alone it stays that way. An unpinned
link carries no profile key at all, so it resolves through your routes
and your fallback every time it opens, following those settings instead
of freezing today's answer into the file. The card says where the thing
will open and what decided it: pinned, or matched acme, or fallback, or
most recent browser. An inferred answer can change tomorrow and a chosen
one cannot, so the two are never shown as though they were the same.

A route can now be removed from the card that told you it was there. Any
row that got where it is going by a pattern offers to undo that pattern,
which is the operation you want most while working out which rules you
actually need.

Dev servers are destinations. localhost:3000 used to fall through to a
web search, having no dot in it. A port now counts the same as a dot, and
so does a name with no dot at all, which cannot be a public host. Those
open over http, because a machine on your desk has no certificate and
https is the one guess that could never work. Loopback, the private
address ranges, and the .local, .localhost and .test suffixes get the
same treatment; everything else is still https, including hosts that
merely sound internal. If you already keep a link to one of these, it
will now open over http where it used to try https.

Nothing about where you go reaches the log. Not a URL, not a host, not a
typed query. lodestar diagnose tails the log into something paste-able,
which made the old habit of recording every opened URL a browsing
history waiting to be shared. Where a link opened is what a bug report
needs; what you opened is yours. A config edit records the name you
chose and never the destination.

Underneath, the card is a state machine in the core rather than logic
living in a panel: which options a row offers, what every key does in
every state, what a return commits. Fifty new tests reach it without an
app running, and they caught a refusal that had been going unsaid.
