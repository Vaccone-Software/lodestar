Windows you did not summon are now left alone.

Real use found the old default too eager: a certificate prompt and a file
reveal both took the screen and hid the window being read. From this release,
windows opened outside Lodestar (another tool, the Dock, ⌘N) float untouched
above your layout, exactly as macOS would have it. They never hide what you
were reading.

The stricter world remains one line away. Set `adopt-new-windows: true` under
`app:` to give external windows the summon treatment: full screen on the
active display, the rest parked, and closing an adopted window restores what
it displaced.

No other behavior changed. Configs that already set the key keep their choice.
