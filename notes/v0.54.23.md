A release that makes dictation start more reliably, takes several gigabytes off Lodestar's launch, and puts more of its plumbing on tested ground.

Dictation no longer blames the recognizer when the Mac's audio system stops answering. The draft now says so in its own words and stops asking on a timer, and pressing lode . asks again. A headset already in its call mode is no longer waited on for a change that is not coming, which used to cost several seconds on every failed start. A newer question to the language model now takes the place of an older one it covers, where it used to wait behind it.

Lodestar's launch used several gigabytes of memory for a few minutes while it read its own records, and did so again every half hour. It now reads only what each job needs, and that cost is a small fraction of what it was.

`lodestar observations` now counts a mark as standing only while it was drawn, counts a mark you came back to once, and says whether marks left standing were sent with the text or left behind. The lines for each app now say how many of those marks were spelling and how many were grammar.

The editor's language and model settings now always reach it in the order you set them. Two changes made close together could arrive the wrong way round and leave the older one in force.

Underneath, the two helpers that run the language models and read the clipboard now use Stoic 0.5's XPC library in place of code written for them. The update check refuses an oversized answer and a redirect to an insecure address. Only one Lodestar running is now proven by a lock, so a number left behind by a crash can never lead to another app being asked to quit. A copied file on a volume that has stopped answering no longer ties up Lodestar while it waits.
