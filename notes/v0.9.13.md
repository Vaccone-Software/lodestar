The handover finally happens.

Behind every update is a moment where the old build must launch the
new one and step aside. That launch was being answered by the system
with "already running" — the old build came forward, the new one
never started, and the watchdog dutifully put everything back. The
pipeline was flawless except for the part where the update happens.

The successor now starts as its own process, takes the session, and
the old build exits the way it always should have. And if a handover
ever does fail, the rollback relaunches the restored build
immediately and says so, instead of leaving a note for a boot that
might be days away.

The manual check narrates every ending now: not writable, nothing
to apply, an unresolved earlier update — each outcome is a flash,
never a silence.
