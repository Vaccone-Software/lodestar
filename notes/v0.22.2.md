A hardening release: one long look at the whole codebase, making the
fast paths honest and the honest paths fast.

The main thread — the one the event tap lives on — stopped paying for
bookkeeping. The observation store used to encode a quarter-megabyte
of JSON and write it to disk on that thread every few busy seconds;
the event ring flushed there too, boot stood behind a full rotation of
ninety days of history, and saving or deleting a breath swept the
window server and wrote the whole state file before the tap returned
its verdict. All of it now runs on background queues, with the same
files, the same ordering guarantees, and a drain at shutdown so
nothing is ever lost to the move. Keystrokes never wait on a disk
again, and launch no longer stands behind the ring.

The per-keystroke surfaces got cheaper in kind. The clipboard strip
cached its source-app icons instead of asking LaunchServices per card
per keystroke, and its list stopped re-sorting ten thousand clips to
show fourteen — the history is newest-first by construction, and a
test now stands on that. The fuzzy scorer folds case once instead of
three times. The launcher counts windows once per query instead of
once per row. Select mode stopped allocating in its match loop, the
app index answers exact names from a dictionary instead of a scan,
and panels remember where the screen is for a quarter second instead
of asking the window server every time they draw.

The advisor's arithmetic got honest. Weekly rates divided lifetime
counts by a week ring that saturates at twelve, so every rate the
coach quoted inflated once a record outlived the ring — a six-month
habit read as double its true pace. Records now remember the week
they first appeared, and every rate divides by the life actually
lived. Retirement waits on the binding's age rather than the store's,
so a chain bound yesterday can no longer be offered up as "never
used". The route chip counts only deliberate profile choices, the
same population the recommendation was priced on. And the rescue
evidence — abandoned chains saved by the launcher — was being filed
under one key and read back under another, so the strongest of it was
invisible; the two sides now agree.

Three traps that hand-edited files could spring are gone: duplicate
calendar spellings in the meetings mapping, a graph table key
colliding with a leaf ("E" and "e" both bound), and duplicate element
ids from a select harvest each used to crash outright. They read as
config quirks now, reported where reporting is owed. An observations
file that will not decode is quarantined and said out loud instead of
being silently overwritten by whatever the ring still held, and the
settings window's numeric bounds agree with the schema they write
into — a test keeps them agreeing.

Eleven new tests pin all of it down.
