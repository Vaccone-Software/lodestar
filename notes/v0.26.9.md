The editor learns the hand it serves.

Two text objects arrive from mini.ai, because that is the editor this
hand comes from: `q` is any quote and `b` is any bracket — the covering
pair wins, innermost first, then the nearest ahead, and an emptied
interior ranks last so the second `dib` grabs the pair around it. `b`
is deliberately taken from vim's parentheses. One key that finds the
pair you mean beats three that ask you to name it.

Surround arrives in the same dialect. `sa` wraps a motion, a text
object, or the visual selection — `saiwq` quotes a word, `saib)`
brackets what the brackets held, `sas]` wraps the line. `sd` unwraps
and `sr` swaps, and both take `q` and `b` as finders, so `sdq` deletes
whichever quotes are actually there. An opening character pads with
spaces, a closing one does not. Vim's `s` was only `cl`; the trade was
made in this hand's own editor long ago.

And the storms that guard every key caught something older than either
feature: a visual command in an empty draft reached for a line that
does not exist and took the app down. It collapses quietly to normal
mode now, with a test bearing its name.
